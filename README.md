# Tower Defence Godot

После билда появится файл "libkeyring.windows.template_release.x86_64.dll". Чтобы добавить его в ".exe" файл, надо установить [Enigma Virtual Box](https://www.enigmaprotector.com/download.html) и запустить его. В открывшемся окне выберите "File" -> "Open Project" и выберите файл "dll injector project.evb" и нажмите "Process".
